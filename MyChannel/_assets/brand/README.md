# Brand assets

Channel-level art: logo, banner (2560×1440, safe area 1546×423), profile image, intro/outro
overlays, end-screen template.

**Make these human-created (or heavily human-edited).** AI-generated images are likely NOT
copyrightable — a human-made logo/wordmark + a trademarked channel name are what actually protect
the brand from copycats. Keep source files (e.g. `.afdesign`, `.psd`, `.svg`) here.
