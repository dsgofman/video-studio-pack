# Character sheet

Reference frames for the channel's recurring characters. Generate each character ONCE
(front / side / 3-quarter, neutral pose, on white) and save here as SVG + PNG. Re-attach the
relevant frame as a reference image on **every** generation that includes the character — this is
what keeps faces/proportions consistent across 60–120 images per video.

Naming: `observer-front.svg`, `observer-side.svg`, `early-human-front.svg`, …
Record the canonical proportions + tool settings in `../style-bible.md` (§4–5).
